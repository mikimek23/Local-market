## About the Project

LocalMarket is a simple website for buying and selling products and services
from local sellers. Customers can browse listings, search for items, view
listing details, save favorites, and create an account.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation links to visit the other pages.

## Main Pages

- **Home:** Introduces LocalMarket and links to the main features.
- **Browse Listings:** Shows available products and services.
- **Search:** Helps users find listings by keyword and category.
- **Listing Details:** Shows information about one listing.
- **Favorites:** Shows listings saved by the user.
- **Customer Profile:** Contains customer information and account sections.
- **Create Listing:** Allows sellers to enter product information.
- **Login and Registration:** Provides account access pages.

## Features

- Browse local products and services.
- Search and filter listings.
- View seller, price, category, and location information.
- Save favorite listings.
- Create a product listing.
- Register and log in to an account.
- Responsive basic layout for different screen sizes.
